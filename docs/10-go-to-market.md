**§ 10 · Go-to-Market**

# 10 — Developer-led, volume-aligned.

### Ideal customer profile

| Tier | Profile |
|---|---|
| **Primary** | AI + Web3 startups (2–20 engineers) building autonomous agents on Ethereum or EVM L2s. Agent marketplaces, DeFi automation, autonomous research, DAO tooling. |
| **Secondary** | Existing AI/agent companies (LangChain, LlamaIndex, MCP server operators) adding payment capabilities to their products. |
| **Tertiary** | Enterprises (fintech, gaming, autonomous research) entering agent infrastructure with small Web3 teams. |

### First 90 days

| Phase | Actions |
|---|---|
| **Days 1–30 — Build in public** | Validation spike + 15 customer interviews · v0.1 published to GitHub + npm · Launch blog post · Posts to HN/Mirror/Warpcast/Twitter · Discord, first 10 users |
| **Days 31–60 — Community growth** | Outreach to 20 agent-building teams · Free Pro tier for 3 months for case studies · 2 technical tutorials · EF + Coinbase grant applications · Join 5 dev communities |
| **Days 61–90 — Conference + accelerator** | Talks to ETHIndia, Devconnect, Agentic Web Summit · Apply Alliance DAO, a16z CSX, Encode Club · Sponsor 2 hackathons · Launch community adapter program ($500/merged adapter) |

### Distribution channels — ranked by priority

| Rank | Channel | Why it works |
|---|---|---|
| 1 | GitHub (open source) | Stars = social proof. Issues = feedback. Inbound trigger for Pro. |
| 2 | npm downloads | Trackable acquisition signal. Every install is a Pro lead. |
| 3 | Ethereum Magicians + ETH Research | Where standards authors and senior devs hang out. |
| 4 | Warpcast (Farcaster) | Web3-native social with high developer signal. |
| 5 | ETHGlobal hackathons | One winning project = hundreds of impressions. |
| 6 | AI/agent communities | LangChain Slack, MCP Discord, AI agent newsletters. |
| 7 | Web3 VC newsletter circuit | Bankless, The Defiant, Messari — feature in dev tooling roundups. |
