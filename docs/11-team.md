# 11 — Founders first. Hires after revenue signal.

### Founding team

| Role | Responsibilities |
|---|---|
| **Founder / CTO** | 5+ years smart contracts. Deep ERC + AA knowledge. Writes initial SDK. Public technical face of the brand. |
| **Co-founder / CEO** | BD + community. Has shipped a Web3 product. Strong network. Leads grants, sales, fundraising. |

| Hire | Month | Profile |
|---|---|---|
| Smart contract security engineer | 4 | Ex-audit firm (Trail of Bits, OpenZeppelin, Certik). Owns security primitives + audit prep. |
| Full-stack engineer | 6 | Next.js + Supabase + wagmi. Owns dashboard. UI/UX instincts critical. |
| Developer relations | 8 | Active in Web3 + AI agent communities. Tutorials, conference talks, dev advocacy. |
| Backend / infra engineer | 10 | Settlement service reliability. Indexer, observability, on-call. |
